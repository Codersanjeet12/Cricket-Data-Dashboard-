# Cricket Data Dashboard (Power BI)

This project showcases a cricket analytics dashboard built in Power BI.

## Features
- Team-wise runs analysis
- Player performance breakdown
- Wickets summary
- Matches mapped by home city

## Tools Used
- Power BI
- Excel (data cleaning)
- SQL (basic queries)

## Key Insights
- Jasprit Bumrah leads with 2150 runs.
- Mumbai Titans scored the highest team runs.
- Kolkata Warriors highlighted with 38 wickets.

- Dashboard file (.pbix)
